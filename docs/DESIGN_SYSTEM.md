# MERAVIN Design System

Version: 1.0

---

# Brand Principles

MERAVIN represents:

- Trust
- Reliability
- Engineering
- Quality
- Simplicity
- Long-term thinking

The interface should never feel decorative.

Every visual decision must increase trust.

---

# Design Philosophy

Minimal.

Timeless.

Professional.

Confident.

Engineering-first.

No visual noise.

# Internationalization

All visible text must support translation.

Never hardcode UI strings in the final architecture.

Use i18next.

English

# Quality Standard

Every component must answer one question:

"Does this increase the customer's trust?"

If the answer is no,

the component should be redesigned.
