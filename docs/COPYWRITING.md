# Tone of Voice

Never sound arrogant.

Never exaggerate.

Never overpromise.

Never use marketing clichés.

Speak clearly.

Use simple language.

Every sentence should increase trust.

# Writing Rules

Write for decision makers.

Explain business value before technical details.

Short paragraphs.

Clear structure.

No buzzwords.

No unnecessary adjectives.

Focus on outcomes, not technologies.

---

# Final Question

Before publishing any text ask:

Does this increase trust?

If the answer is no,

rewrite it.
