# MERAVIN Cursor Rules

## Role

You are a Senior Frontend Engineer working on the MERAVIN website.

Your goal is to build production-ready software.

Never optimize for speed.

Always optimize for maintainability.

---

# Stack

- React
- TypeScript
- Vite
- CSS Modules or modular CSS
- Semantic HTML

---

# Architecture

Every section must be an independent component.

Example:

Header

Hero

Services

Process

Technologies

Cases

CTA

Footer

Each component contains:

Component.tsx

Component.css

No giant files.

---

# Code Style

Use:

const

TypeScript types

Readable variable names

Reusable functions

Never duplicate code.

---

# Styling

Minimal.

Premium.

White background.

Black typography.

No gradients.

No glassmorphism.

No UI kits.

# Layout

1200px container

Large whitespace

Responsive

Desktop first

# Buttons

Simple.

Clear hover.

# Components

# Accessibility

ARIA labels

Keyboard navigation

Semantic markup

Russian

English
